# 行测速算训练营

面向公务员、事业单位考试的纯前端速算练习工具。基于 React + TypeScript + Vite，数据保存在浏览器本地，无需业务服务器。

## 本地开发

```bash
nvm install 20
nvm use 20
npm install
npm run dev
```

浏览器访问终端提示的本地地址（默认 http://localhost:5173）。

## 构建

```bash
npm run build
npm run preview
```

## MVP 功能
- 学习总览、速算技巧库、专项练习
- 单题计时、自动判分、速算思路与解析
- 错题本、训练统计
- JSON 数据导入导出
- 浏览器本地存储，不需要账号和服务器
